RootCause

Can an LLM agent find what broke,
better than a simple rule?

RootCause is an LLM agent that reads an incident’s metrics, traces and logs to name the service that broke. Here it is scored against a simple heuristic on 20 recorded incidents, with every run shown, failures included.

How it works

  1. A fault is injected into the OpenTelemetry Demo, a shop made of 28 services, and its metrics, traces and logs are recorded as a snapshot. The ground truth is stored separately.
  2. Every channel that could name the fault, such as feature-flag events, log wording or delay markers, is stripped, and an automated scan checks each snapshot for leaks.
  3. Each solver gets the same snapshot and, except in the vague-alert ablations, the same alert. The heuristic names the service whose fault signal rose most. Agent v0 reads raw metric series, traces and logs; agent v1 adds a ranking of what changed, per-service health and a service map. Both run as a tool loop on Gemini 3.5 Flash-Lite or Nemotron 3 Super (a GLM 5.3 Flash batch of agent v1 is in progress).
  4. Answers are scored by rules fixed before the first run. On single-fault incidents the top-ranked cause must be in the accepted set; on two-fault incidents each true cause named anywhere in the ranked list earns half. A control is only right with “no incident”, and abstaining counts as wrong.
  5. The agent’s cited evidence is checked against the telemetry: does it exist (grounded), and does it point at something anomalous (distinctive)?

Honest limits

  • Twenty incidents from one demo app on one laptop. This is a small benchmark, not a general claim.
  • Every solver gets the exact fault onset (t=0 is the injection time), and several alerts hint at the culprit’s functional area. The vague-alert ablation gives agent v1 one generic alert for every incident: on Nemotron it doubles false alarms on the controls and lowers fault accuracy by a borderline 12 points, so the alerts’ hints probably help. The same ablation on Gemini is running.
  • Free models only: Gemini 3.5 Flash-Lite on its free tier and Nemotron 3 Super on NVIDIA’s free trial endpoint, both at temperature 0. The spread across runs measures API nondeterminism, not sampling.

Results are regenerated from the run records with python -m rootcause site.
